	nslookup (Name Server Lookup)
		nslookup (FLAGS) {DOMAIN}
		FLAGS
			-type=PTR {IP} | reverse DNS lookup

	dig (DNS Lookup)
		dig (RECORD) {domain.com} @{IP}
		FLAGS
			RECORD TYPES
				A  | Find IPv4 addresses
				AAAA | Find IPv6 addresses
				TXT | Find text records (api keys, tokens or flags)
				MX | Find mail servers
				CNAME | Find aliases to the IP (A records)
				NS | Find the name server of the domain
				any | everything from above (I suggest not using this, many dns servers block it)
			Zone Transfer
				axfr | used to find private A and CNAME records linked to the NS domain (internal records)

	dnsenum (DNS subdomains enumeration)
		dnsenum -f {WORDLIST} --dnsserver {DNS_SERVER} {subdomain}.domain.com
		FLAGS
			-f | sets the wordlist for subdomains enum
			-o | output file
			-p | set Threads
			-r | recursive, further enumerate the found subdomain

	Hashcat
		hashcat -m {MODE} -a {ATTACK} {HASHFILE} {WORDLIST}
		FLAGS
			-m specifies the hashtype in numeric format, e.g -m 1000 is NTLM. use man hashcat for more codes.
			-a specifies the attackmode, -a 0 = 1 password after the other from the wordlist
		EXAMPLE
			hashcat -m 1000 -a 0 hashes.txt rockyou.txt
	Hashes
		md5sum {file}
		sha1sum
		sha256sum
		sha512sum
			outputs the hash as a hexadecimal
		
		generally passwords are saved as hashes not as cleartext. The password entered gets converted to a hash and 		compared to the hash saved. Hashes are very hard to reverse engineer so its way safer than just storing 		cleartext passwords.
		You can salt hashes by adding a string to the original cleartext before it gets hashed which changes the 		hash drastically
		Linux stores these password hashes in /etc/shadow only readable by root. Line contains 9 fields seperated 		by :
		Password fields are saved in this format $prefix$options$salt$hash		prefix determines the encryption hashing scheme

	NMap
		nmap (IP)/24 (FLAGS) (SCRIPTS)
		FLAGS
			-sn 				| ping scan host (no ports, only active hosts)
			-sL 				| List Target IPs/names
			-sT 				| TCP connect, complete Handshake
			-sS 				| stealth scan, only 1st step of Handshake
			-sU 				| UDP scan
			-F 				| scans only 100 most common ports (instead of 1000)
			-pX-Y 				| scans ports from x to y. -p- scans EVERY port.
			-O 				| OS detection (isn't always reliable)
			-sV 				| Service Version scan
			-A 				| O & sV together plus other things
			-Pn 				| treat every Host as online and force scan.
			-v 				| verbosity level (-v or -vv)
			-oN {FILENAME} 			| saves as normal output
			-oG 				| GREPable output
			-D RND:xyz 			| to set up decoy IP adresses. Your IP will be put in that pool of 							  random IP Adresses. Combine it with a proxy.

			--disable-arp-ping 		| to disable arp pinging. This is better at evading EDRs as it 								  forces a L3 ping and does not come across as a high frequency 							  ping sweep/tcp request

			--source-port xyz 		| to force nmap to send traffic from the chosen port
			--data-length xyz 		| adds a random extra data to the packet frame so they do not look 							  like standard nmap probes (some EDRs look into it)
		TIMINGS
			-T0 paranoid 9.8h for 100 most common ports (5 min between each port)
			-T1 sneaky 27.53 min for 100p (15 sec between every 2 ports)
			-T2 polite 40.56 sec for 100p (0.4 sec for every port)
			-T3 normal 0.15 sec for 100p
			-T4 aggressive 0.13 sec for 100p
		SCRIPTS (categories)
			Needs to always start with --script xyz
			auth 				| Determination of authentication credentials.
			brute 				| Executes scripts that try to log in to the respective service by 							  brute-forcing with credentials.
			discovery 			| Evaluation of accessible services.
			exploit 			| This category of scripts tries to exploit known vulnerabilities 							  for the scanned port.

			version 			| Extension for service detection.
			vuln 				| Identification of specific vulnerabilities.

	TCPDump
		ip a s
		sudo tcpdump (FILTERS) (FLAGS)
		FILTERS
			host {IP}				| Limit TO & FROM {IP} host
			port {PORT} 				| Limit TO & FROM {PORT} port
			src xyz host/port 			| Limit FROM xyz host/port
			dst xyz host/port			| Limit TO xyz host/port
			Protocol IP, IP6, UDP, TCP, ICMP or ARP | Limits the search for this protocol
	
			and 					| Captures packets where both conditions are true
			or 					| Captures packets when one conditions is true
			not 					| Captures packets when the condition is not true
		FLAGS
			-i eth interface
			-w save to file
			-r read from file
			-c Limit sniffs to certain count
			-n dont resolve ip -nn dont resolve protocols
			-v -vv -vvv verbosity
